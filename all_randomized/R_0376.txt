**Executive Summary:**

We’ve identified a highly critical, actively exploited zero-day vulnerability (CVE-2024-3400) within Palo Alto Networks PAN-OS GlobalProtect software. This vulnerability allows for unauthenticated remote code execution with root privileges, posing a significant risk to our network security and data integrity. Multiple actors are currently exploiting this vulnerability, and we’ve observed a geographically diverse range of attack attempts. Immediate action is required to mitigate this threat.

**Key Findings & Analysis:**

* **Vulnerability Details:** CVE-2024-3400 is a command injection vulnerability within the GlobalProtect feature of PAN-OS. The vulnerability stems from improper sanitization of SessionIDs, allowing attackers to execute arbitrary commands.
* **Exploitation Status:** The vulnerability is *actively* being exploited in the wild. Kroll observed multiple geographically dispersed attack attempts, indicating a coordinated effort.  Crucially, we have *not* yet detected successful exploitation on patched devices.
* **Affected PAN-OS Versions:** The vulnerability impacts PAN-OS versions 120.2, 11.0 and 11.1.  Specific versions are detailed in Context 7.
* **Kroll’s Response:** Kroll is actively investigating the scope of the exploitation, analyzing attack patterns, and providing actionable intelligence. We’ve alerted clients and are monitoring for compromised systems.
* **Immediate Mitigation Steps (Critical):**
    1. **Patch Immediately:** Prioritize patching all affected PAN-OS devices to the latest versions (10.2.9-h1, 11.0.4-h1, 11.1.2-h3, and subsequent releases). See Context 7 for specific release dates.
    2. **Implement Threat Prevention Controls:** Palo Alto Networks customers can block attacks using Threat IDs 95187, 95189 and 95191 (available in Applications and Threats content version 8836-8695 and later).
    3. **Monitor Network Traffic:**  Increase monitoring of network traffic for suspicious activity, particularly related to GlobalProtect connections.
    4. **Review Security Configurations:** Conduct a thorough review of GlobalProtect configurations to ensure they align with best practices.
